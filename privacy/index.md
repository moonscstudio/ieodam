# 이어담 개인정보처리방침

시행일: 2026년 11월 26일

이어담(Ieodam, 이하 "앱")은 사용자가 자기 NAS나 구글 드라이브, 기기에 둔 책(TXT·EPUB·만화 ZIP/CBZ·PDF)을 읽고, 여러 기기에서 읽던 위치를 이어 주는 전자책 리더입니다. 이 방침은 앱이 어떤 정보를 어디에 두고 어떻게 쓰는지 설명합니다.

## 1. 한 줄 요약

- 앱 개발자는 **서버를 운영하지 않으며, 사용자의 개인정보를 수집하거나 받아 보지 않습니다.**
- 앱이 다루는 정보는 **사용자의 기기**와 **사용자가 직접 연결한 저장소**(사용자의 NAS 또는 구글 드라이브)에만 저장됩니다.
- 광고, 분석 도구, 사용자 추적, 오류 보고 도구를 쓰지 않습니다.

## 2. 앱이 다루는 정보와 저장 위치

| 정보 | 쓰는 목적 | 저장 위치 |
| --- | --- | --- |
| 책 파일 | 책을 열어 보여 주기 | 기기, 또는 사용자가 고른 NAS·구글 드라이브 |
| 읽던 위치, 책갈피, 읽은 시각, 기기 이름(예: "iPad") | 다른 기기에서 이어 읽기 | 기기, 그리고 사용자가 고른 NAS 또는 구글 드라이브의 앱 폴더 |
| 화면 설정(글꼴, 글자 크기, 넘김 방향 등) | 읽기 화면 유지 | 기기 |
| NAS 주소, 아이디, 비밀번호 | 사용자의 NAS에 접속 | 기기 (비밀번호는 iOS 키체인·안드로이드 암호화 저장소에 보관) |
| 구글 계정 이메일 주소 | 어느 계정으로 연결됐는지 앱 화면에 표시 | 기기 |

위 정보는 개발자에게 전송되지 않습니다. 앱은 사용자가 입력한 NAS 주소와, 구글 드라이브를 연결한 경우 구글 서버에만 접속합니다.

## 3. 구글 드라이브 연결

- 구글 드라이브 연결은 선택 사항이며, 사용자가 "구글로 로그인"을 눌러야만 시작됩니다.
- 앱은 구글 드라이브 권한 중 **`drive.file`**만 요청합니다. 이 권한으로는 **앱이 만들거나 사용자가 앱에서 연 파일만** 다룰 수 있고, 드라이브의 다른 파일은 볼 수 없습니다.
- 앱은 사용자의 드라이브에 `Ieodam` 폴더를 만들고, 그 안에 책과 읽던 위치·책갈피 파일을 둡니다.
- 구글 로그인과 드라이브 이용에는 [구글 개인정보처리방침](https://policies.google.com/privacy)이 함께 적용됩니다.
- 이어담이 구글 API로 받은 정보의 사용과 전송은 [Google API 서비스 사용자 데이터 정책](https://developers.google.com/terms/api-services-user-data-policy)(제한적 사용 요건 포함)을 따릅니다. 앱은 이 정보를 책 읽기와 이어 읽기 기능에만 쓰며, 광고에 쓰거나 다른 사람에게 넘기거나 팔지 않습니다.

## 4. 개인정보의 제3자 제공·처리 위탁

개발자는 개인정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하는 일이 없습니다. 사용자가 직접 연결한 NAS나 구글 드라이브에 저장되는 정보는 사용자 자신의 저장소에 보관되는 것입니다.

## 5. 보유 기간과 삭제

- 기기에 저장된 정보는 앱을 지우면 함께 지워집니다. 앱의 "로그아웃"이나 저장소 설정에서 연결 정보를 지울 수도 있습니다.
- NAS나 구글 드라이브에 저장된 책과 읽던 위치 파일은 사용자가 그 저장소에서 직접 지울 수 있습니다(구글 드라이브의 `Ieodam` 폴더 등).
- 구글 계정의 앱 접근 권한은 [구글 계정 → 보안 → 서드 파티 앱 및 서비스](https://myaccount.google.com/connections)에서 언제든 취소할 수 있습니다.

## 6. 앱이 쓰는 권한

- **인터넷**: 사용자의 NAS와 구글 드라이브에 접속합니다.
- **로컬 네트워크(iOS)**: 집 와이파이 안의 NAS에 접속합니다.
- **파일 공유(iOS)**: Finder·iTunes로 앱에 책을 넣을 수 있게 합니다.

## 7. 정보 보호

- NAS 비밀번호는 기기의 보안 저장소(iOS 키체인, 안드로이드 암호화 저장소)에 보관합니다.
- 구글 드라이브와는 암호화된 연결(HTTPS)로 통신합니다. NAS와의 연결 방식(HTTP 또는 HTTPS)은 사용자가 NAS 설정에서 정한 주소를 따릅니다.

## 8. 어린이

앱은 어린이를 대상으로 만들지 않았으며, 어린이의 개인정보를 따로 수집하지 않습니다.

## 9. 사용자의 권리

개발자는 사용자의 개인정보를 갖고 있지 않으므로, 열람·정정·삭제는 위 5항처럼 사용자의 기기와 저장소에서 직접 할 수 있습니다. 궁금한 점은 아래 연락처로 문의해 주세요.
